카드를 누르면 뒤집히면서 정답 해설과 효과음이 터집니다! 🔄⚡

주성분 🐱

1. 주어 (Subject)

#누가 #무엇이 #문장의주인공

🐱🫵

"냥이가 마라탕을 남겼다!"

🔄 클릭해서 뒷면 해설 보기! (FLIP)
주어 공식 💡

동작/상태의 '주체'!

문장에서 '누가/무엇이'에 해당하는 핵심 성분입니다.

✨ 핵심 조사: 이 / 가 / 께서 / 에서

예시: 고양이가 / 선생님께서

🐱 냥선생: "마라탕 먹은 '주인공'이 바로 나다냥!"
주성분 🐨

2. 서술어 (Predicate)

#어찌하다 #어떠하다 #무엇이다

🍀✨

"오늘도 완전 럭키비키잖아!"

🔄 클릭해서 뒷면 해설 보기! (FLIP)
서술어 공식 💡

주어를 풀이하고 마무리!

주어의 동작, 상태, 성질을 설명하여 문장을 끝맺는 성분!

✨ 형태: 동사/형용사/체언+이다

예시: 먹는다(동사) / 예쁘다(형용사) / 학생이다(체언+이다)

🐨 럭키쿼카: "결론을 내어주는 최종 마무리 판사다 쿼카!"
주성분 🐰

3. 목적어 (Object)

#무엇을 #누구를 #행위의타겟

🧋💥

"철수가 탕후루를 먹었다!"

🔄 클릭해서 뒷면 해설 보기! (FLIP)
목적어 공식 💡

동작의 직접적인 대상!

타동사가 나타내는 행위의 타겟(목적)이 되는 성분입니다.

✨ 핵심 조사: 을 / 를

예시: 밥을 먹다 / 친구를 만나다

🐰 토끼반장: "먹히는 대상인 '탕후루'가 바로 목적어야!"
🔥 시험단골!
주성분 🐹

4. 보어 (Complement)

#되다 #아니다 #앞에오는말

🙅‍♂️❌

"나는 더 이상 바보가 아니다!"

🔄 클릭해서 뒷면 해설 보기! (FLIP)
보어 치트키 🔥

'되다 / 아니다' 앞 필수 보충!

서술어 '되다', '아니다' 바로 앞에 와서 뜻을 보충해주는 성분!

✨ 공식: [ 보어 + 이/가 ] + 되다/아니다

예시: 어른이 되다 / 학생이 아니다

🐹 햄스터: "주어랑 생긴 게(이/가) 똑같아서 속기 쉬우니 '되다/아니다'를 꼭 확인해!"
부속성분 🐱

5. 관형어 (Adnominal)

#어떤 #체언(명사)꾸밈

👟✨

새 신발을 신고 춤을 춘다!

🔄 클릭해서 뒷면 해설 보기! (FLIP)
관형어 공식 💡

체언(명사)만 전담 수식!

'어떤' 상태인지를 설명하며 명사/대명사/수사를 꾸밉니다.

✨ 형태: 관형사, 체언+의, 용언+ㄴ/ㄹ

예시: 예쁜 옷 / 시골의 풍경

🐱 냥선생: "뒤에 명사(신발, 옷)가 오면 관형어라냥!"
부속성분 🐨

6. 부사어 (Adverbial)

#어떻게 #어디서 #용언꾸밈

🏃💨

"매점에 겁나게 빠르게 튀어갔다!"

🔄 클릭해서 뒷면 해설 보기! (FLIP)
부사어 공식 💡

서술어나 문장 전체 수식!

'어떻게, 언제, 어디서' 행위가 일어났는지 더 맛깔나게 꾸며줍니다.

✨ 조사/어미: 에/에서/에게/-게/-이

예시: 아주 예쁘다 / 학교에서 놀다

🐨 럭키쿼카: "동사나 형용사, 부사를 맛깔나게 칠해주는 양념 양념~"
독립성분 🐰

7. 독립어 (Independent)

#아차 #어머나 #부름과감탄

😱💥

"아차! 수행평가 깜빡했다!"

🔄 클릭해서 뒷면 해설 보기! (FLIP)
독립어 공식 💡

다른 성분과 얽히지 않는 마이웨이!

감탄, 부름, 응답 등을 나타내며 혼자 독자적으로 쓰이는 성분!

✨ 형태: 감탄사, 체언+호격조사(아/야)

예시: 야! 너두? / 철수야, 이리와!

🐰 토끼반장: "보통 쉼표(,)나 느낌표(!)랑 같이 등장해!"
